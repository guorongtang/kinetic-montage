# v13 风格规范

所有常数来自 `presets/v13.json`，引擎按这些值渲染。
改风格 = 改 preset，不要改 `engine/`。

---

## 1. 色彩

| token | hex | 用途 |
|---|---|---|
| `ink` | `#0B0B0D` | 近黑底 |
| `cream` | `#F3F0E8` | 米白底 / 亮字 |
| `blue` | `#2F5BFF` | 强调 / 链接 |
| `red` | `#FF3B1F` | 警告 / 否定 |
| `text` | `#14161A` | 米白底上的字 |
| `muted` | `#8A8A90` | 黑底小标 / 单位 |
| `muted2` | `#6B635A` | 米白底小标 |
| `sub` | `#4A4B45` | 收尾卡副标 |

一屏只有一个底色。配色序列在 `draft` 里是
`ink → cream → red → blue → cream → ink → blue → red`，避免连续同色。

## 2. 字体

| 用途 | 字体 | 字号 | 字重 | 字距 |
|---|---|---|---|---|
| 数字 | Avenir Next Condensed（macOS）/ Archivo Narrow（其他） | 560（带单位 420） | 900 | −3% |
| 中文 | PingFang SC / Noto Sans SC | 190–300 | 900 | −3.5% |
| 小标 kicker | 中文 | 42 | 800 | 0 |
| 截图 caption | 中文 | 54 | 900 | 0 |
| 收尾 wordmark | 数字字体 | 104 | 900 | −3% |
| 收尾 tagline | 中文 | 52 | 700 | 0 |
| 收尾 url | 中文 | 44 | 800 | 0 |
| CTA | 中文 | 30 | 800 | 0 |

中文永远逐行手写 `lines`，不要让浏览器自动断行。

---

## 3. 版式

- 左边距 110px；kicker 在 `(110, 150)`。
- 数字整体居中：`left = W/2 - (数字宽 + 34 + 单位宽)/2`，基线 `H/2 + 30`。
- 单位在数字右侧 56px，字母基线 `H/2 + 30 + 0.36 * 字号`。
- word 左对齐，垂直居中，行高 1.06；每行 mask wipe 上移。
- 截图 `shot` 模式：
  - 背景：同一张图 cover + `blur(26px) brightness(.55)`，再叠 `rgba(8,8,10,.45)`
  - 前景：`min(84% W, 80% H)` 居中，y 偏 −20
  - 底部渐变：从 `0.55H` 到 `H`，`rgba(6,6,8,0) → .82`
  - caption 在 `(110, H−120)`；文字固定 cream，后面垫 `rgba(6,6,8,.82)` 圆角底板（padding 26×16，圆角 12），不随 `bg` 变色，避免截图明暗导致半行看不见
- 收尾卡：图标中心 `(W/2, 300)`，160×160 圆角 40；wordmark y=520；tagline 640；url 740；CTA 330×78 在 y=810，圆角 16。

## 4. 运动

| 动作 | 曲线 / 时长 |
|---|---|
| 镜头入场 | `p = (t − t0) / min(shotLen, 0.42)`，`easeOutQuint` |
| 数字入场 | 前 12%：粒子从半径 260–880 飞入，alpha 0.15→1 |
| 数字出场 | 镜头最后 30%（`qNow > 0.70`）：向外炸开 + 放大 1→2.6 || 数字抖动 | 静止段 ±1.7px，`sin(9t)` / `cos(7.3t)` |
| word | alpha `p*3`；行 i 延迟 `0.18`；位移 `1.6 * 字号`，clip 从上往下揭开 |
| 图片 | 1.04 → 1.10，`easeInOutCubic` |
| 碎片 | 非 number 镜头，`p < 0.085`（约 2 帧）：12×7 块，位移 ±160/±120 |
| glitch bar | 碎片帧叠 5 条横向切片，alpha `0.5*(1−p/0.085)` |
| 收尾 | 图标 0.6→1.0 缩放 0.28s；文字 0.12/0.35/0.55/0.75s 依次淡入 |

**没有叠化、没有推拉、没有缓动切点。** 只有硬切和 2 帧碎片。

### numberExit

- `"shot"`（默认）：数字一直可读到镜头最后 30%，然后炸开。新片子用这个。
- `"legacy"`：v13 原始行为 —— 入场（0.42s）一结束数字就瞬间消失。仅 `examples/v13-regression` 用，为了保持逐字节一致。

### imageMotion

- `"shot"`（默认）：截图在整个镜头里持续推近（1.04 → 1.10）。
- `"legacy"`：v13 原始行为 —— 推近只发生在入场 0.42s 内，之后静止。

## 5. 节奏

v13 的指纹（`kinetic qa` 会对比）：

```json
{
  "shots": 43,
  "cuts": 41,
  "cutsPer10s": 19.3,
  "avgShot": 0.52,
  "endcardRatio": 0.26,
  "typeMix": { "word": 19, "number": 14, "image": 9, "endcard": 1 }
}
```

经验值：

- 0.3–0.9 秒/镜；截图可 1.0–1.4 秒（v13 有两处）。
- 前 22 秒讲完故事，最后 8 秒只放品牌。
- 每 3–4 个 beat 插一张真截图，防止“纯字卡”看累。
- 数字连续出现时，背景要换色，否则会糊成一片。
- 旁白词首前 0.25–0.5 秒切画面。

---

## 6. 文案

- 一行 ≤ 6 个汉字；一个 word 镜头 ≤ 2 行。
- 数字 ≤ 5 个字符；单位单独放。
- 一个镜头只讲一件事。
- 动词优先：「拖进去」「点一下」「压到」。
- 不要形容词堆砌；不要“赋能/闭环/生态”。
- 所有数字必须能在产品里复现（v13 的 9.76MB 就是 `food.jpg` 的真实大小）。

---

## 7. 颗粒 / 扫描线

v13 的源码里写了 `post()`，但把颗粒画到了隐藏 buffer 上，**成片其实没有颗粒**。
本引擎默认 `post: { grain: 0, scanlines: 0, flicker: 0 }` 以对齐 v13。

想要颗粒（已修正到可见画布）：

```json
"post": { "grain": 0.07, "scanlines": 0.03, "flicker": 0.01 }
```

注意：开了颗粒后，帧不再逐字节可复现（噪点 tile 是 seeded，但仍会改变画面）。
